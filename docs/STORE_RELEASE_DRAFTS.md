# Play 스토어 출시 문서 초안

출시 체크리스트(`RELEASE_CHECKLIST.md`)의 문서 항목을 위한 초안이다. 세 가지: 데이터 안전 양식 답안, 개인정보 처리방침에 더할 문구, 스토어 설명. 모두 **현재 코드가 실제로 하는 일** 기준으로 썼고, 아직 없는 기능(계정 삭제 유보, 구독)은 "구현 뒤"로 표시했다. 처리방침 본문은 웹 저장소(`/privacy/`)에 있으므로 거기에 반영한다. 문구는 PROJECT_CONTEXT의 "Things Not To Overpromise"를 따른다.

## 1. 데이터 안전 양식 (Play Console) 답안

| 질문 | 답 | 근거 |
|---|---|---|
| 데이터를 수집하거나 공유하나 | 수집함, 제3자와 공유하지 않음 | Firebase(Google)는 처리 위탁. 광고 SDK·분석 SDK 없음 |
| 모든 데이터가 전송 중 암호화되나 | 예 | Firebase SDK가 TLS로 통신. 평문 통신 없음 |
| 사용자가 삭제를 요청할 수 있나 | 예 — 앱 안 계정 삭제(구현 뒤) + 웹 삭제 요청 링크 | 체크리스트 "계정 삭제 경로". 유보 14일 |
| **개인 정보** | 이름, 이메일 주소, 사용자 ID — Google 로그인 시에만, 계정 관리 목적, 선택 수집 | Firebase Auth. 로그인 없이도 앱 사용 가능 |
| **앱 활동** | 활동 기록(분류·제목·시작·끝·메모·운동 세트), 할 일, 루틴·데일리 큐 완료, 설정값 — 로그인 시 동기화·웹 통계 목적, 선택 수집 | Firestore `users/{uid}/flowlog/...`. 로그인 전엔 폰에만 저장 |
| **앱 정보 및 성능** | 비정상 종료 로그, 진단 정보 — 앱 안정성 목적, 릴리즈 빌드에서만 | Crashlytics(`MainActivity`에서 debug 빌드는 수집 끔) |
| **기기 또는 기타 ID** | Crashlytics 설치 ID | Crashlytics 기본 동작 |
| 위치, 연락처, 사진, 건강 데이터 | 수집 안 함 | 해당 권한 없음 |
| 데이터 보존·삭제 | 계정 삭제 요청 후 14일 유보 뒤 영구 삭제(구현 뒤). 지운 기록은 서버에 식별자와 삭제 표시만 남음(구현 뒤) | 체크리스트 |

주의: 웹 대시보드가 받는 설문 응답·강의 계획표 데이터는 웹 저장소 쪽에서 같은 양식에 맞춰 적는다.

## 2. 개인정보 처리방침에 더할 문구 (초안)

> **수집하는 정보.** Flowlog는 로그인 없이도 쓸 수 있으며, 이때 기록은 휴대전화 안에만 저장됩니다. Google 계정으로 로그인하면 활동 기록(분류, 제목, 시작·종료 시각, 메모, 운동 세트), 할 일, 루틴과 설정값이 Google Firebase(Firestore)에 저장되어 다른 기기와 웹 대시보드에서 볼 수 있게 됩니다. 로그인 시 Google이 제공하는 이름, 이메일, 사용자 ID를 계정 식별에 씁니다.
>
> **오류 보고.** 앱이 비정상 종료되면 Firebase Crashlytics가 기기 모델, OS 버전, 설치 ID와 오류 정보를 수집합니다. 기록 내용은 포함되지 않습니다.
>
> **운영자의 접근.** 서비스 운영과 문제 해결을 위해 운영자가 서버에 저장된 기록을 열람할 수 있습니다. 열람은 운영 목적에 한하며 다른 용도로 쓰거나 제3자에게 제공하지 않습니다.
>
> **삭제.** 앱의 설정에서 "계정과 데이터 삭제"를 요청할 수 있습니다. 요청 후 14일 동안은 다시 로그인하면 삭제를 취소하고 기록을 복원할 수 있으며, 14일이 지나면 서버의 기록과 계정이 영구 삭제됩니다. 앱을 쓸 수 없는 경우 [웹 삭제 요청 페이지]에서 요청할 수 있습니다. 기록 하나를 지우면 서버에는 삭제 표시와 식별자만 남고 내용은 지워집니다. (구현 뒤 게시)
>
> **내보내기.** 언제든 설정에서 모든 기록을 CSV 또는 JSON 파일로 내보낼 수 있습니다.
>
> **요금.** 기록과 통계는 무료입니다. 서버 저장(동기화)과 웹 대시보드는 베타 기간 동안 무료이며, 이후 월 구독으로 전환될 예정입니다. 전환 시점과 조건은 앱과 이 페이지에서 미리 알립니다.

## 3. 스토어 설명 초안

**짧은 설명(80자 이내)**
> 버튼 한 번으로 시간을 기록하고, 확정된 기록으로 하루를 돌아보는 가벼운 시간 기록 앱

**전체 설명**
> Flowlog는 가볍게 기록하고 정직하게 돌아보는 시간 기록 앱입니다.
>
> • 버튼 한 번으로 활동 타이머를 시작합니다. 수면·휴식·공부·업무·학교·식사·운동 같은 분류를 고르고, 제목은 최근에 자주 쓴 것이 추천됩니다.
> • 할 일에 시간을 연결하면, 완료 여부만이 아니라 실제로 쓴 시간이 쌓입니다.
> • 오늘 시간표, 분류별 합계, 어제와의 비교, 최근 7일 평균을 봅니다.
> • 루틴 블록과 부드러운 알림(기상 후, 식사 후, 취침 전), 집중 모드(방해 금지), 홈 화면 위젯.
> • 타이머를 켜는 걸 잊었다면 지난 활동을 직접 추가할 수 있습니다.
> • 모든 기록은 휴대전화에 먼저 저장되어 인터넷 없이도 쓸 수 있고, 언제든 CSV·JSON으로 내보낼 수 있습니다.
> • Google 계정으로 로그인하면 기록이 동기화되어 웹 대시보드(flowlog.pfkfks.org)에서 더 긴 기간의 통계를 볼 수 있습니다. 동기화와 웹 대시보드는 베타 기간 무료이며, 이후 월 구독으로 전환될 예정입니다.
>
> Flowlog는 광고가 없고, AI 코칭이나 자동 습관 형성을 약속하지 않습니다. 추천은 모두 휴대전화 안의 규칙으로 계산됩니다.

쓰지 않는 표현(PROJECT_CONTEXT): "습관을 자동으로 만들어 준다", "최적의 루틴", "인생을 바꾼다", "AI 분석", "장기 패턴 분석".
